How I build with AI

AI helps me move fast. Tests keep it right.

AI writes much of the first draft. I own the design, review every change, and don’t ship until the tests pass. This is the loop I used for Tally and for this site.

  1. Design the system first

    I write down who it’s for, the data model, the APIs and what “done” means before any code exists.

  2. Build with an AI pair programmer

    I work with Claude and OpenAI models to draft features, then read, question and rewrite what they produce.

  3. Test it like production

    Automated browser tests click through every feature. Tally ships with 32 of them, including two phones syncing at once.

  4. Ship it the same day

    Push to GitHub, deploy to GitHub Pages, and it’s live in about a minute. Then I start the next one.
